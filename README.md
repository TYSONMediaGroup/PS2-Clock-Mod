An authentic recreation of the iconic PlayStation 2 system clock and ambient crystal orbit display, built with the LÖVE 2D engine.

Designed to bring the nostalgic PS2 clock to your desktop as a native screensaver or animated wallpaper.

The behavior and orb geometry are referenced from the PS2 BIOS documentation on [Gamicus](https://gamicus.gamepedia.com/PlayStation_2_internal_display_clock).
